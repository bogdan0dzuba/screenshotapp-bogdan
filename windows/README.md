# Скриншутер для Windows

Предварительная версия 0.1.0 для Windows 11. Для Intel и AMD нужен x64, для Windows на ARM - Arm64. Тип системы указан в «Параметры → Система → О системе».

1. Распакуйте ZIP целиком и запустите `ScreenshotApp-Bogdan.exe`. Runtime .NET включен в ZIP. Сборка без цифровой подписи, Windows может показать предупреждение при запуске.
2. Нажмите `Ctrl + Shift + A` в любом приложении и выделите область мышью. `Esc` отменяет выделение. Хоткей можно изменить в главном окне.
3. В редакторе протяните стрелку или область размытия. Для текста выберите «Текст» и щелкните по снимку. Для отмены правки нажмите `Ctrl + Z`.
4. Выберите «Сохранить PNG» (`Ctrl + S`) или «Копировать» (`Ctrl + C`). Последняя версия каждого снимка автоматически сохраняется на полке.
5. Перетащите миниатюру с полки в приложение, которое принимает PNG-файлы, либо в папку Проводника, отличную от папки хранения. Кнопка «Копировать» рядом с миниатюрой копирует изображение.

Полка показывает 20 последних файлов. PNG хранятся в `%LOCALAPPDATA%\ScreenshotApp-Bogdan\Captures`, настройки хоткея - в соседнем файле `hotkey.json`. В главном окне есть кнопка «Открыть папку». Скриншутер сохраняет данные локально. Для работы хоткея держите приложение открытым. Его можно свернуть.

## Сборка на Windows

Нужен .NET 10 SDK. Из корня репозитория выполните команду, при необходимости заменив `win-x64` на `win-arm64`.

```powershell
dotnet publish windows/ScreenshotApp.Windows -c Release -r win-x64 --self-contained true -o dist/windows
dotnet run --project windows/SmokeChecks -c Release
```

Smoke-проверка требует активного рабочего стола. Она использует мышь, хоткей и буфер обмена.

Для приемки на Windows 11 Pro 25H2 пройдите шаги 1–5, затем измените хоткей и перезапустите приложение. Если подключено несколько дисплеев с разным масштабом, сделайте снимок через границу экранов и проверьте края PNG.
