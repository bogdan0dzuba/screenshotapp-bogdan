## Результат

Подписанная локальная сборка установлена и запущена:
`/Users/bogdandzuba/Applications/Скриншутер.app`.

В 5.61 обычный захват показывал панель выбора до получения изображения. Передача клавиатурного фокуса закрывала нативное меню, а последующий захват получал уже измененный экран. Теперь обычная область использует существующий `selectFrozenRegion(using:)`: кадр сохраняется перед показом панели, затем область вырезается из него. Изменения экрана во время выделения в результат не попадают. При отсутствии общего разрешения записи экрана системный выбор источника может закрыть меню до получения кадра.

Работа выполнена в отдельной ветке `codex/capture-open-menus` на базе `8922004` (5.61). Накопленные изменения исходной рабочей папки и другая рабочая копия сохранены. Публикация на GitHub и обновление других компьютеров не выполнялись.
